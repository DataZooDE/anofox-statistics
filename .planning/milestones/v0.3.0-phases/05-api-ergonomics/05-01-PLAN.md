<objective>
Fix the pre-existing INTERNAL crash where a rolling `fit_predict(...) OVER (...)` throws `INTERNAL: access index 0 within vector of size 0` when a partition's leading frame has fewer than `n_features+1` rows. The fix is to return a NULL prediction for degenerate frames — standard rolling-regression behavior (D per CONTEXT.md locked decision), not an error.

This is the phase TRACER: it is the highest-risk item, is end-to-end (SQL query → C++ window/aggregate finalize → observable NULL result), touches the same finalize-guard shape every expansion task later relies on, and the correct template already exists verbatim in `src/window_functions/ols_fit_predict.cpp:258-268`. Task 1 writes a repro `.test` that identifies WHICH finalize path throws; Task 2 fixes it and back-fills the scaling guard across every fit_predict finalize that still uses a weaker threshold.

Purpose: prove the NULL-for-degenerate-frame path end-to-end before the error-surfacing and rename expansion waves build on it.
Output: `test/sql/ergo01_window_null.test` (green) + scaling `min_obs` guard in every fit_predict finalize path.
</objective>
