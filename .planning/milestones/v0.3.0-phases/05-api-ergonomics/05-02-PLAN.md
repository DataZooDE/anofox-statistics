<objective>
Make invalid input fail fast with clear, typed, actionable errors instead of the current generic `"OLS fit failed: ..."` wrapper (which throws `InvalidInputException` regardless of the real error class) and the silent unknown-option-key ignore. Two mechanisms:

1. A `ThrowFromFfiError` dispatch helper (new header) that reads the already-populated-but-currently-ignored `AnofoxError.code` and throws the correct DuckDB exception class per the locked taxonomy (D per CONTEXT.md: `InvalidInputException` for user data/shape problems, `FunctionException` for numerical failures). Applied at all 10 generic `!success` throw sites plus the non-window aggregate finalize paths.
2. Unknown MAP option keys rejected at bind time in `ParseFromValue` (currently the final else says "Unknown keys are silently ignored"), with a message naming the key and listing valid keys — catching typos early.

Purpose: deliver ERGO-01 (clear, actionable, typed errors) and ERGO-02 (early bind-time validation) against the already-hardened window NULL path from Plan 01.
Output: `src/include/error_dispatch.hpp`, updated throw/finalize sites, unknown-key rejection, and two new `.test` files.
</objective>
